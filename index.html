Frequently Asked Questions

Got Questions? We Have Answers.

Everything you need to know about MindHarbourAI products, security, and deployment.

Ragify is our AI-powered knowledge retrieval engine. It converts your company's documents, PDFs, and data into dense vector embeddings stored in a FAISS vector database. When a user asks a query, Ragify instantly retrieves the most relevant semantic contexts and uses modern LLMs to generate accurate, source-cited responses without data hallucination.

SailTask uses fine-tuned NLP models to parse meeting notes, emails, and document summaries. It identifies key action items, assigns responsibility, sets deadline estimates, and automatically triggers external workflows via REST APIs, webhooks, or task management integrations.

Unlike standard text LLMs, Cadox is specifically built to inspect and understand engineering CAD data formats (such as STEP, IGES, and SolidWorks files). It parses geometric metadata, assembly hierarchies, and component attributes to help engineers query design specs and accelerate design analysis.
